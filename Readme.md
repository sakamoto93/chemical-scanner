# Chemical Scanner

試薬瓶のラベルから CAS 番号を OCR で読み取り、化合物情報を取得し、一覧化・Excel 出力を行う Web アプリケーション。

---

# プロジェクトの目的

研究室で使用している試薬管理を効率化することを目的とする。

最終目標は既存の試薬管理台帳と統合し、

- CAS番号
- 化合物名
- 法令情報
- SDS
- 在庫管理

などを一元管理できるシステムを構築する。

ただし、最初から全機能を作るのではなく、段階的に開発する。

### Step1-3

CAS番号抽出・化合物情報取得

#### 実装内容

1. **CAS番号がある試薬の場合**
   - 正規表現でCAS番号パターンをマッチング
   - チェックディジット検証
   - CAS番号から化合物情報を取得

2. **CAS番号がない試薬の場合**
   - OCRで抽出された化合物名や化学式を識別
   - PubChem APIで化合物情報を検索
   - 化学式またはIUPAC名からCAS番号を逆引き

#### 完成条件

- CAS番号がある試薬：CAS番号を抽出し、化合物名を取得できること
- CAS番号がない試薬：化合物名や化学式からCAS番号を取得できること
- 両方のパターンに対応し、一覧に統合できること

# 実装上の考慮事項

## OCR精度とその制限

### 現状（Step1-2完了時点）

- **PaddleOCR** を使用してカメラ映像からテキストを抽出
- 信頼度の高いテキスト（95%以上）は正確に認識
- 複数言語（英語、日本語、中国語など）が混在するラベルに対応可能

### 課題と今後の対応

1. **CAS番号がない試薬瓶への対応**
   - 直接CAS番号を読み込めない試薬が存在
   - 化合物名や化学式から逆引きしてCAS番号を取得する必要がある
   - **Step1-3で実装予定**：PubChem APIを使用した逆引き機能

2. **OCR誤認識への対応**
   - 低信頼度（<70%）のテキストは除外する検討
   - 複数フレーム平均を取る（改善予定）
   - ユーザーマニュアル入力による確認フロー

3. **言語依存性**
   - 現在は英語（lang='en'）に設定
   - 日本語試薬に対応する場合は `lang='ja'` に変更必要

## PubChem API活用戦略

### Step1-3での実装予定

```
OCR結果（化合物名/化学式）
    ↓
PubChem API検索
    ↓
CAS番号取得
    ↓
化合物情報一覧に追加
```

### 検索優先順位

1. CAS番号による直接検索（最も正確）
2. IUPAC名による検索
3. 化学式による検索
4. 商品名による検索（曖昧性が高い）
